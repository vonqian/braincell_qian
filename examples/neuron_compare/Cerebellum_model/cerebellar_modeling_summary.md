## 2. MF 建模

采用 **Lorenzi et al. 2023 (PLOS Comp Biol)** 的参数方案：

| 参数            | 推荐值             | 说明                    |
| ------------- | --------------- | --------------------- |
| MF 发放率范围      | 0–80 Hz（泊松分布）   | 生理范围内                 |
| MF 时间常数 τ_MF  | 3.5 ms          | 小脑特有的快速时间常数（比大脑皮层快得多） |
| 活跃 MF 比例 f_MF | 0.2–0.5（典型 0.3） | 并非所有 MF 同时活跃          |

## 3.基于 Glomerulus 的 MF→GrC & GoC 建模

### 3.1 问题的提出

传统建模方式中，MF→GrC 和 GoC→GrC 作为两组独立的连接矩阵生成，**忽略了小脑皮层最核心的解剖结构——肾小球（glomerulus）**。这种"扁平化"的连接模型既不够生物真实，也难以自然产生前馈抑制的时间动力学。

### 3.2 Glomerulus 作为网络节点

**核心定义：**

```
每根 MF 的 rosette 数（单个 folium 内）**16-17**
MF rosette = 1 个 glomerulus
```

即：每一个 MF 终末对应一个肾小球（glomerulus）。

**示例：**
```
1000 个 MF rosette
      ↓
1000 个 glomeruli
```

**建模意义：** 所有 MF↔GrC↔GoC 的连接都围绕 glomerulus 建立，glomerulus 成为连接矩阵中的"虚拟节点"：

```
  MF ──→ Glomerulus ──→ GrC 树突
  GoC ──→ Glomerulus ──→ GrC 树突（抑制）
```

### 3.3 GrC 接入方式

**实验数据依据：** 每个 GrC 通常有 **4 条树突**，每条树突进入一个不同的 glomerulus。

```
GrC
├─ glom 13
├─ glom 52
├─ glom 211
└─ glom 890
```

**算法实现：**

```python
for grc in all_grcs:
    glom = sample(local_glomeruli, n=4)  # 随机选择 4 个邻近 glom
```

**自动生成的连接：**

```
MF ──→ glom ──→ GrC
```

> **优势：** 无需单独生成 MF→GrC 矩阵 —— 连接关系从 "GrC 选择 glom → glom 对应 MF" 的逻辑**自动派生**。

### 3.4 GoC 接入方式

GoC 的接入包含两部分，分别对应其形态学的两个关键结构：

#### (a) GoC 树突 — 接受 MF 和 PF 输入

- 树突范围：约 **100–200 μm**
- 输入来源：MF 直接输入 + PF（平行纤维）输入
- 覆盖范围：约 10个 glomeruli (estimate)

#### (b) GoC 轴突 — 体现 glomerulus 结构的关键

**轴突支配规模：** 一个 GoC 轴突可支配约 **10³ 量级的 glomeruli**（不同文献从几百到上千）。

**算法实现：**

```python
for goc in all_gocs:
    target_glom = sample(local_glomeruli, n=1000)
```

**自动生成的连接：**

```
GoC ──→ glomerulus ──→ 该 glom 中的所有 GrC 树突
```

这自动形成 **GoC→GrC 抑制通路**，无需额外生成连接矩阵。

### 3.5 前馈抑制的时间动力学

当 MF 活跃时，它同时：

1. **直接兴奋 GrC**（通过 glom）—— 快速兴奋通路
2. **兴奋 GoC**（通过树突）—— GoC 在约几十毫秒后通过轴突支配 glom 以**抑制 GrC**

这是一个经典的**前馈抑制（Feedforward Inhibition）回路**：

```
MF ──→ Glomerulus ──→ GrC    （快速兴奋）
 │                        ↑
 └──→ GoC ──→ Glomerulus ┘    （延迟抑制，~10-50 ms）
```

该回路构成了 **GrC 层的时间窗控制**机制，决定了 GrC 能够被激活的时间窗口宽度。

### 3.6 算法流程总图

```
                    ┌─────────────────────┐
                    │   MF 发放 (0-80Hz)   │
                    └─────────┬───────────┘
                              │
                              ▼
                    ┌─────────────────────┐
                    │   Glomerulus 层      │  ←── GoC 轴突支配 (~1000/GoC)
                    │  (N_glom 个节点)     │  ←── GrC 树突选择 (4/grC)
                    └──┬──────┬──────────┘
                       │      │
                       ▼      ▼
               ┌─────────┐  ┌─────────┐
               │  GrC 层  │  │  GoC 层  │
               │(快速激活)│  │(延迟激活)│
               └────┬────┘  └────┬────┘
                    │            │
                    │    ┌───────┘
                    │    │  (延迟~10-50ms)
                    ▼    ▼
              ┌─────────────────┐
              │   GrC←GoC 抑制   │
              │ (通过 glom 通路)  │
              └─────────────────┘
```

### 3.7 延迟参数

| 连接路径 | 延迟 (ms) |
|---|---|
| MF→GoC | 1.0 |
| GoC→GrC（通过 glom） | 0.5 |
| MF→GrC（通过 glom） | 1.5 |
| GrC→GoC | 2.5 |
| GoC↔GoC（缝隙连接） | 0.1 |

## 4. GrC→SC/BC 连接

### 4.1 连接形式

| 连接 | 形式 | 参数 |
|---|---|---|
| GrC→SC | 随机稀疏 | — |
| GrC→BC | 随机稀疏 | — |
| SC→SC | 局部随机 | P = 0.10 |
| SC→BC | 局部随机 | P = 0.08 |
| BC→SC | 局部随机 | P = 0.05 |
| BC→BC | 忽略或极低 | P = 0–0.02 |

### 4.2 局部连接生成算法

SC 和 BC 仅与**空间邻近**的 GrC、SC、BC 建立连接，体现小脑皮层分子层的局部微环路结构。

## 6. GoC 网络（缝隙连接）

GoC 之间通过**电突触（缝隙连接）**形成广泛的耦合网络：

| 指标 | 期望值 | 参考文献支持 |
|---|---|---|
| GoC 缝隙连接耦合比例 | ~80% 相邻对 | Vervaeke 2010 |
| 每个 GoC 的缝隙连接数量 | ~10 个 | Vervaeke 2010 |
| GoC 化学突触连接比例 | ~20% 可检测对 | Hull & Regehr 2012 |
| 化-电共存比例 | 高（大多数） | Hull & Regehr 2012 |

> **当前建模建议：** 可作为可选模块，初期模型可以先忽略 GoC↔GoC 缝隙连接，待基础网络验证后再加入。

## 7. 整体网络架构图

```
  ┌───── MF 输入 (0-80Hz 泊松) ─────┐
  │           │                      │
  │           ▼                      ▼
  │    ┌──────────────┐    ┌──────────────┐
  │    │  Glomerulus   │◄──│  GoC 树突     │
  │    │  (节点层)     │    │  (接受 MF)    │
  │    └──┬───┬───┬───┘    └──────┬───────┘
  │       │   │   │              │
  │       ▼   ▼   ▼              ▼
  │    ┌──────────────────┐  ┌──────────────┐
  │    │  GrC 层          │◄─│  GoC 轴突     │
  │    │  (4条树突/glom)  │  │  (支配~1000   │
  │    └────────┬─────────┘  │   glom/GoC)   │
  │             │            └──────────────┘
  │             │ PF               ↑
  │             ▼                  │
  │    ┌──────────────────┐        │
  │    │ SC │ BC │ PC      │────────┘
  │    │ (局部微环路)      │
  │    └──────────────────┘
  │             │
  └─────────────┘ 浦肯野细胞输出 → 小脑核团
```

### 关键设计原则

1. **Glomerulus 作为中心节点** —— 所有 MF↔GrC↔GoC 连接通过 glom 自动派生，无需分别生成连接矩阵
2. **前馈抑制回路** —— MF→(GrC ↑, GoC ↓) 构成 GrC 时间窗控制
3. **模块化 GoC** —— 树突接收输入（MF + PF）、轴突发送抑制（→glom→GrC），功能分离
4. **局部微环路** —— SC/BC/PC 在分子层形成局部随机连接，处理 GrC 的 PF 输入
